## 1. ОБЩЕЕ ОПИСАНИЕ

1.1 Цель

Превратить главную страницу из «просто библиотека» в «путь к стандарту». Показать эволюцию: от простого API → production-доказательство (Decima-8) → цель (Boost).

1.2 Ключевое сообщение

> «libwui — это не хобби. Это инфраструктура для C++ UI, построенная на BSL, доказанная в Decima-8, нацеленная в Boost.»

1.3 Целевая аудитория

| Сегмент | Что их зацепит |
| ------- | -------------- |
| C++ разработчики | BSL, нет зависимостей, заголовочные файлы |
| Инженеры embedded | 1.3 МБ бинарь Decima-8, 60 FPS |
| Коммерческие студии | BSL = можно использовать в закрытых продуктах |
| Boost-энтузиасты | Путь к submission, стандарт C++17 |

Карточка 1: Плоское владение

```
📦 Flat Ownership
Никаких циклических ссылок.
Метод window->add_control(button, rect) не передает владение окну. 
Окно хранит невладеющие ссылки на контролы для отрисовки и проброса событий.
```

Карточка 2: Система событий

```
🎯 Event System
Типобезопасные события через окно. Лямбды, без макросов.

win.on_click([](int x, int y) {
    handle_click(x, y);
});
```

Карточка 3: Система тем

```
🎨 Theme System
Встроенная система тем. Светлая, тёмная, кастомная — 
переключение без пересборки.
```

Карточка 4: Локали
```
🌍 Locales & i18n
UTF-8 из коробки. Поддержка локалей, RTL, 
плюрализация без внешних библиотек.
```

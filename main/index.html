About WUI

WUI is a cross-platform library for creating graphical user interfaces in C++. The library uses C++17 and provides a minimalist API. Currently supports Windows (XP — 11) and Linux (glibc 2.23+).

WUI was designed to provide developers with a simple and effective tool for creating cross-platform GUI applications in C++. The library allows you to focus on application logic rather than platform-specific interface implementation.

🖥️ Cross-Platform

Windows (WinAPI + GDI) and Linux (X11 + xcb) support. macOS support planned.

📦 Minimalist API

Simple and intuitive interface. No code generators, no complex build systems.

🎯 Event-Driven

Flat subscription model. Any object can subscribe to events of any control.

Architecture

The project is based on three key entities:

Window

Receives system events and manages controls. Handles event dispatching to subscribers, triggers control redraws, and provides graphic context.

Control

Visual interface element (buttons, input fields, etc.). Handles events, stores its states, and renders itself on the graphic context provided by the containing window.

Graphic

Interface for rendering that abstracts platform-specific drawing methods. Currently implemented for Windows GDI/GDI+ and Linux xcb/cairo.

Supporting components:

  • common — basic types (rect, color, font)
  • event — mouse, keyboard, internal and system events
  • theme — visual theme constants system
  • locale — text content storage subsystem

Key Features

📋 Flat Ownership Model

WUI uses a flat control ownership model: all window controls are owned by a single parent object (typically a dialog class), which stores them in std::shared_ptr. When the parent is destroyed, all controls are automatically freed.

class DialingDialog {
    std::shared_ptr<wui::window> window;
    std::shared_ptr<wui::text> text;
    std::shared_ptr<wui::button> cancelButton;
};

🎯 Flat Event Subscription

Window acts as a central event dispatcher. Any object can subscribe to events it needs.

// Subscribe to keyboard and system events
std::string sub_id = window->subscribe(
    [this](const wui::event& ev) {
        if (ev.type == wui::event_type::keyboard) {
            // Hotkey logic
        }
    },
    wui::event_type::keyboard | wui::event_type::system
);

// Unsubscribe by ID
window->unsubscribe(sub_id);

🎨 Theme System

Built-in theme support with customizable visual styles. Light, dark, and custom themes available.

🌍 Localization

UTF-8 support out of the box. Locale system for multi-language applications.

⚙️ Configuration

Application configuration management (Windows registry, ini-files, JSON).

🔧 Custom Controls

Create and integrate your own controls with clear base classes and interfaces.

Code Example

// Simple example: window + button
#include <wui/framework/framework.hpp>
#include <wui/window/window.hpp>
#include <wui/control/button.hpp>

int main() {
    wui::framework::init();

    auto window = std::make_shared<wui::window>();

    auto button = std::make_shared<wui::button>("Click me",
        []() {
            // Button click handler
        });

    window->add_control(button, { 10, 10, 100, 35 });

    window->init("Hello WUI!", { -1, -1, 400, 300 });
    wui::framework::run();

    return 0;
}

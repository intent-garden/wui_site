WUI (Window User Interface) — кроссплатформенная C++ библиотека для создания графических интерфейсов. Сосредоточьтесь на логике приложения, а не на платформо-зависимых деталях реализации.

О библиотеке

WUI — это кроссплатформенная библиотека для создания графического интерфейса пользователя на C++. Библиотека использует C++17 и имеет минималистичный API. В настоящее время поддерживается Windows (XP — 11) и Linux (glibc 2.23 и выше).

WUI разработана с целью предоставления разработчикам простого и эффективного инструмента для создания кроссплатформенных GUI-приложений на C++. Библиотека позволяет сосредоточиться на логике приложения, а не на особенностях реализации интерфейса для каждой платформы.

🖥️ Кроссплатформа

Поддержка Windows (WinAPI + GDI) и Linux (X11 + xcb). В планах — macOS.

📦 Минималистичный API

Простой и интуитивный интерфейс. Без генераторов кода, без сложных систем сборки.

🎯 Событийная модель

Плоская модель подписки. Любой объект может подписаться на события любого контрола.

Архитектура

Проект основан на трёх ключевых сущностях:

Window

Принимает системные события и управляет контролами. Осуществляет рассылку событий подписчикам, инициирует перерисовку контролов и предоставляет им графический контекст.

Control

Визуальный элемент интерфейса (кнопки, поля ввода и т.д.). Обрабатывает события, хранит свои состояния и рисует себя на графическом контексте, предоставляемом содержащим его окном.

Graphic

Интерфейс для отрисовки, абстрагирующий платформо-зависимые методы рисования. В настоящий момент реализовано рисование на Windows GDI/GDI+ и Linux xcb/cairo.

Вспомогательные компоненты:

  • common — основные типы (rect, color, font)
  • event — события мыши, клавиатуры, внутренние и системные события
  • theme — система констант для поддержки визуальных тем
  • locale — подсистема для хранения текстового контента

Возможности

📋 Плоская модель владения

WUI использует плоскую модель владения контролами: все контролы окна владеются одним объектом-родителем (обычно классом диалога), который хранит их в std::shared_ptr. При уничтожении родителя все контролы автоматически освобождаются.

class DialingDialog {
    std::shared_ptr<wui::window> window;
    std::shared_ptr<wui::text> text;
    std::shared_ptr<wui::button> cancelButton;
};

🎯 Плоская подписка на события

Окно выступает в роли центрального диспетчера событий. Любой объект может подписаться на нужные ему события.

// Подписка на события клавиатуры и системы
std::string sub_id = window->subscribe(
    [this](const wui::event& ev) {
        if (ev.type == wui::event_type::keyboard) {
            // Логика горячих клавиш
        }
    },
    wui::event_type::keyboard | wui::event_type::system
);

// Отписка по ID
window->unsubscribe(sub_id);

🎨 Система тем

Встроенная поддержка тем оформления с настраиваемыми визуальными стилями. Светлая, тёмная и пользовательские темы.

🌍 Локализация

UTF-8 из коробки. Система локалей для многоязычных приложений.

⚙️ Конфигурация

Управление конфигурацией приложения (реестр Windows, ini-файлы, JSON).

🔧 Свои контролы

Создание и интеграция собственных контролов с понятными базовыми классами и интерфейсами.

Пример кода

// Минимальный пример: окно + кнопка
#include <wui/framework/framework.hpp>
#include <wui/window/window.hpp>
#include <wui/control/button.hpp>

int main() {
    wui::framework::init();

    auto window = std::make_shared<wui::window>();

    auto button = std::make_shared<wui::button>("Нажми меня",
        []() {
            // Обработчик нажатия
        });

    window->add_control(button, { 10, 10, 100, 35 });

    window->init("Hello WUI!", { -1, -1, 400, 300 });
    wui::framework::run();

    return 0;
}
